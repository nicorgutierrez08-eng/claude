# Movi — Website

Landing page for Movi, the iOS movie ranking app built on head-to-head comparisons.

## To run locally

Just open `index.html` in any browser. No build step needed.

## To host on GitHub Pages

1. Go to your repo Settings → Pages
2. Set source to `main` branch, `/movi-website` folder
3. Your site goes live at `https://nicorgutierrez08-eng.github.io/claude/movi-website/`

## Stack

- Pure HTML/CSS — no frameworks, no build tools
- Google Fonts (Righteous + Poppins)
- All SVG icons inline
